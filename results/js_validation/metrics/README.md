# metrics/

## 1. Source
Generated by `code/js_validation/evaluation/compute_cohens_kappa.py`, which loads `data/js_validation/human_labels.csv` as gold labels and scores every model output in `../model_outputs/` against it. `js_evaluation_summary.json` is the script's direct output: per-model exact-match accuracy, Jaccard similarity, micro/macro-averaged precision/recall/F1, and per-label (A-U) precision/recall/F1/support. The script also writes `human_agreement_summary.json` and `human_disagreements.csv` to this same directory (inter-annotator agreement diagnostics), which are not part of this release.

## 2. Next-step input
Terminal output used directly for the paper's model-comparison numbers; not consumed by another script.
