# statistics/

## 1. Source
Generated by `code/statistics/merge.py`, which merges the static and dynamic credential-exfiltration CSVs produced by `code/statistics/statistics.py --results-dir <analysis_results> --out-dir <dir>` (`rq3_static_exfil_targets.csv`, `rq3_static_server_actions.csv`, `rq3_dynamic_exfil_targets.csv`, `rq3_dynamic_server_actions.csv`) and classifies each credential-exfiltration action into one of four channels: Email, Messaging APIs (Telegram), Custom Web Panel / HTTP outbound, Local File Logging. `credential_exfiltration_channels.csv` is `merge.py`'s direct output file.

## 2. Next-step input
Terminal output used directly for the paper's exfiltration-channel breakdown; not consumed by another script.

## 3. Paper results supported
These result files support the analyses and findings reported in Tables 3 and 4 of the paper.
