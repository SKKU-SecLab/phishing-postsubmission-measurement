# probing/

## 1. Source
Generated by `code/probing/threat_actor_clustering.py`, which extracts deterministic forensic artifacts (email, Telegram handle, git author, SMTP credentials) from `results/dynamic_analysis_blackwidow/analysis_results/` (and optionally from raw kit source files and from `code/probing/kit_backend_exposure_scanner.py`'s `hunt_results.json`), then clusters kits that share any artifact into campaigns via Union-Find.
- `clustering_summary.json` — overall clustering statistics (`--out-dir` output `clustering_summary.json`).
- `cluster_summary.csv` — one row per cluster of size >= 2: cluster id, cluster size, date range, dominant identifier types, and a sample of kit names in that cluster.

## 2. Next-step input
Terminal output describing threat-actor campaigns; not consumed by another script in this repository.

## 3. Paper results supported
These result files support the analyses and findings reported in Tables 4 and 5 of the paper.
