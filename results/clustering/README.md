# clustering/

## 1. Source
Produced by the 4-stage pipeline in `code/clustering/`, run in order:

1. `01-extract_functions.py` reads every JSON file in `results/dynamic_analysis_blackwidow/analysis_results/` and extracts triggered JS functions -> `all_functions.json` (+ `extract_errors.json` if any input file failed to parse).
2. `02-embed_codebert.py` reads `all_functions.json` and embeds each function with CodeBERT -> `embeddings_codebert.npy` + `embeddings_ids.json`.
3. `03-cluster_sample.py` reads the embeddings, tunes HDBSCAN over a parameter grid, and clusters the functions -> `labels.npy`, `cluster_stats.json`, `tuning_results.json`, and a per-cluster sample `sampled_clustered.json`.
4. `make_centroids.py` reads the embeddings + labels and picks the sample closest to each cluster centroid -> `cluster_centroids.json`.

Files included in this release: `cluster_centroids.json`, `cluster_stats.json`, `labels.npy`. The larger intermediate files (`all_functions.json`, `embeddings_ids.json`, `sampled_clustered.json`, `tuning_results.json`, `extract_errors.json`, `embeddings_codebert.npy`) are regenerated by re-running the pipeline above and are not included here.

## 2. Next-step input
- `all_functions.json` -> input to step 2 (`02-embed_codebert.py`).
- `embeddings_codebert.npy` + `embeddings_ids.json` -> input to step 3 (`03-cluster_sample.py`) and to `make_centroids.py`.
- `labels.npy` -> input to `make_centroids.py`.
- `cluster_centroids.json` / `sampled_clustered.json` are the human-reviewed samples used for manual cluster labeling, feeding the behavior-category scheme used in `code/js_validation/`.
