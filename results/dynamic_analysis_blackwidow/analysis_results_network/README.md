# analysis_results_network/

## 1. Source
Generated by `code/dynamic_analysis_blackwidow/crawl.py --analyze --network-only` (fast analyze mode: skips per-field typing/validation tracing and only records submit-centered network traces), using `FormAnalyzer.py`. One `analysis_results_network_<date>_<kit-name>_<timestamp>.json` file per kit.

## 2. Next-step input
`code/dynamic_analysis_blackwidow/analyze_network.py` post-processes these files (`python analyze_network.py analysis_results_network/analysis_results_network_*.json`) into a human-readable network-request summary, optionally with `--csv`.
