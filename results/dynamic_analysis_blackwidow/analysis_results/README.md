# analysis_results/

## 1. Source
Generated by `code/dynamic_analysis_blackwidow/crawl.py --analyze` (dynamic form-behavior crawl of a phishing kit), using `FormAnalyzer.py` as the analysis engine. Each `analysis_results_<date>_<kit-name>_<timestamp>.json` file records the JS function calls, DOM changes, network requests, and HTML5 validation observed while a form on that kit was filled in and submitted.

## 2. Next-step input
- `code/clustering/01-extract_functions.py` reads every JSON file in this directory to extract triggered JS functions for clustering.
- `code/statistics/statistics.py --results-dir` reads this directory to compute the aggregate statistics.
- `code/probing/threat_actor_clustering.py --results-dir` reads this directory to extract forensic artifacts (email / Telegram / git identifiers) for threat-actor clustering.
