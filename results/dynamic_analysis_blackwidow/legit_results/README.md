# legit_results/

## 1. Source
Generated by `code/dynamic_analysis_blackwidow/crawl.py --legit` (dual-phase CDP + JS-visible header capture on a legitimate website) or `--legit --manual` (human-driven session for anti-bot / SSO-protected sites, via `LegitManualSession.py`), using `LegitAnalyzer.py`. Each `manual_<domain>_<timestamp>.json` file records the header-level form-submission behavior of a real, non-phishing site, used as a baseline for comparison against phishing-kit behavior.

## 2. Next-step input
Used as the legitimate-site baseline compared against `../analysis_results/` when assessing phishing-kit form behavior; not consumed by an automated downstream script in this repository.
